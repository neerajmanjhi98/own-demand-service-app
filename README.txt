OWN DEMAND SERVICE APP - DEMO

How to run:
1. Extract the ZIP file if you downloaded the ZIP.
2. Open the folder.
3. Double-click index.html.
4. It should open in Chrome, Edge, or another browser.
5. Select a service, fill the booking form, and click Confirm Demo Booking.
6. Use the status buttons to demonstrate booking status updates.

Important:
This is a front-end academic prototype. It runs locally in your browser and does not use a real backend/database or contact real service providers. Explain it honestly as a working prototype/demo. Do not enter real sensitive personal information.
